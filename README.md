This project is an attempt to organize the array of data involved in the World War 2 naval combat simulator "War on the Sea", available from Steam, and produced by Killer Fish.

This is a PowerShell script that finds and pulls in the most recent campaign save from the user's campaign save folder, and converts the JSON into an Excel spreadsheet
that shows the status of every ship and every land location in that campaign with the aid of the various campaign setup and data files.

The Excel document is unique to that save and is written out to either the user's local Documents folder, or their OneDrive folder.
